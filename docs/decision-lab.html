HYPOTHESIS CHALLENGER · BETA

好的 AI 不該只會附和你。
它應該先挑戰你的想法。

輸入想進入的市場與商業條件。系統會找出最容易讓計畫失敗的前提，計算需要通過的驗證門檻，列出支持與缺失的證據，設計一場小額反證實驗。

透明聲明：這是可運作的「規則式決策引擎」原型，並非已接入大型語言模型的自主 AI。市場總體數據由世界銀行提供；產品需求與 Qloo 文化偏好資料尚待正式 API 權限。沒有證據的地方不會捏造。

每個數字都是你的假設，不會自動變成「真實數據」。預算限制是本次挑戰的 NT$3,000。
